# Egyptian Japanese Company website

Website of The Egyptian Japanese Company for Import and Export, in Arabic and English.

**Live site:** https://youssefseyam212.github.io/egyptian-japanese-site/

## Tech stack

- HTML and CSS, with no build step
- Hosted on GitHub Pages

## Run locally

```bash
git clone https://github.com/youssefseyam212/egyptian-japanese-site.git
cd egyptian-japanese-site
```

Then open `index.html` in a browser.

## Structure

- `index.html`: the page
- `assets/`: images and styles
